SanitizeAI Log Cleaner

Before you paste work logs into an AI tool like ChatGPT, paste them here first. It automatically hides client names, IP addresses, emails, usernames, and passwords inside your browser.

  • Finds client names even with spaces, hyphens, underscores, or inside domains
  • Replaces details with clean placeholders like [CLIENT_1] or [IP_1]
  • Includes a lookup table so you can match placeholders back to real values
